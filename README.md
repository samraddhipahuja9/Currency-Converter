# Currency-Converter
A simple and responsive Currency Converter web application built using HTML, CSS, and JavaScript. This project allows users to convert one currency into another using real-time exchange rates fetched from a Currency API.
Features
Convert currencies in real time
Supports multiple international currencies
Dynamic country flags update
Clean and responsive UI
Fetch API integration for live exchange rates
Technologies Used
HTML
CSS
JavaScript
Currency API
Flags API
How It Works

The application fetches live exchange rates from the Currency API and calculates the converted amount based on the selected currencies and entered amount.

API Used
Currency API
Flags API for country flags
Example

USD → INR
EUR → USD
GBP → JPY

This project is beginner-friendly and helps in understanding:

API fetching using fetch()
DOM manipulation
Event handling
Async/Await in JavaScript
